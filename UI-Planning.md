# Personal Finance Manager: UI Plan

## 🏠 Home Page
- Shows total balance
- Quick summary of expenses
- Chart with spending categories

## 💸 Expense Page
- Add new expense
- Choose category (food, rent, fun)
- View list of all expenses

## 📈 Insights Page
- Graph of monthly spending
- Forecast next month's expenses
- See savings progress

## 📷 Receipts Page
- Upload receipt images
- View uploaded receipts

## ⚙️ Settings
- Dark mode / Light mode
- Currency options
